# 🎯 Установка и тестирование расширения

## Шаг 1: Установка в Chrome

1. **Открой Chrome Extensions**
   ```
   chrome://extensions/
   ```
   Или через меню: ⋮ → Расширения → Управление расширениями

2. **Включи режим разработчика**
   - Переключатель "Режим разработчика" в правом верхнем углу

3. **Загрузи расширение**
   - Нажми "Загрузить распакованное расширение"
   - Выбери папку: `C:\Users\Offspring\Work\passwordgenerator\chrome-extension`
   - Расширение должно появиться в списке

4. **Закрепи иконку** (опционально)
   - Нажми на иконку пазла 🧩 в toolbar
   - Найди "Pswdgen - Secure Password Generator"
   - Нажми на булавку 📌

## Шаг 2: Базовое тестирование

### Тест 1: Popup открывается
```
1. Кликни на иконку расширения
   ИЛИ
2. Нажми Ctrl+Shift+P
```
✅ Должен открыться popup с 3 вкладками

### Тест 2: Генерация Password
```
1. Вкладка "Password" (должна быть активна)
2. Настрой длину (слайдер)
3. Выбери типы символов (чекбоксы)
4. Нажми "Generate"
```
✅ В поле должен появиться пароль

### Тест 3: Генерация Passphrase
```
1. Переключись на вкладку "Passphrase"
2. Настрой количество слов
3. Нажми "Generate"
```
✅ Должна появиться фраза типа "Correct-Horse-Battery-Staple1234"

### Тест 4: Генерация PIN
```
1. Переключись на вкладку "PIN"
2. Выбери длину (4/6/8)
3. Нажми "Generate"
```
✅ Должен появиться PIN код

### Тест 5: Copy работает
```
1. Сгенерируй любой пароль
2. Нажми кнопку 📋 (Copy)
3. Открой блокнот и вставь (Ctrl+V)
```
✅ Пароль должен вставиться

```
1. Открой test.html

2. Кликни на поле (чтобы оно было в фокусе)

3. Нажми Ctrl+Shift+G
```
✅ Пароль должен сгенерироваться и вставиться

## Шаг 6: Проверка настроек

```
1. Открой popup

2. Измени настройки (длину, типы символов)

3. Закрой popup

4. Открой снова
```
✅ Настройки должны сохраниться

## Шаг 7: Проверка истории

```
1. Сгенерируй несколько паролей

2. Открой Chrome DevTools (F12)

3. Перейди в Application → Storage → Local Storage → chrome-extension://...

4. Найди ключ "history"
```
✅ Должен быть массив с последними паролями

## 🐛 Troubleshooting

### Popup не открывается
```
Решение:
1. Проверь chrome://extensions/
2. Убедись что расширение включено
3. Нажми кнопку "Перезагрузить" (🔄)
4. Попробуй снова
```

### Insert не работает
```
Решение:
1. Убедись что поле в фокусе (кликни на него)
2. Попробуй на test.html
3. Если не работает - используй Copy вместо Insert
4. Проверь консоль (F12) на ошибки
```

### Passphrase не генерируется
```
Решение:
1. Открой консоль (F12)
2. Посмотри ошибки
3. Проверь что файл существует:
   chrome-extension/wordlists/eff-long-wordlist.txt (106 KB)
4. Перезагрузи расширение
```

### Context menu не появляется
```
Решение:
1. Перезагрузи расширение в chrome://extensions/
2. Перезагрузи страницу (F5)
3. Убедись что кликаешь на input/textarea
4. Проверь что расширение включено
```

### Ошибки в консоли
```
Решение:
1. Открой chrome://extensions/
2. Найди расширение
3. Кликни "Ошибки" (если есть)
4. Скопируй текст ошибки
5. Проверь что все файлы на месте
```
