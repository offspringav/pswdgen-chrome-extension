## Name
Pswdgen - Secure Password Generator

## Summary (132 characters max)
Generate cryptographically secure passwords, passphrases, and PINs. Privacy-first, works offline. No data collection.

## Description (16,000 characters max)

Generate strong, cryptographically secure passwords instantly with Pswdgen - the privacy-focused password generator that works completely offline.

🔐 KEY FEATURES

• Multiple Generation Types
  - Passwords: Customizable length (8-64 chars) with uppercase, lowercase, digits, and special characters
  - Passphrases: Memorable word-based passwords using EFF wordlist (3-8 words)
  - PINs: Secure numeric codes (4, 6, or 8 digits)

• Quick Access
  - Popup: Click icon or press Ctrl+Shift+P (Cmd+Shift+P on Mac)
  - Context Menu: Right-click any input field → Generate Password
  - Keyboard Shortcut: Ctrl+Shift+G (Cmd+Shift+G on Mac) for instant generation

• Smart Features
  - Auto-insert into active field or copy to clipboard
  - Remembers your preferred settings
  - History of last 50 generated passwords (stored locally)
  - Exclude ambiguous characters option (0, O, l, 1, I)

• Privacy & Security
  - 100% offline - no internet connection required
  - No data collection or tracking
  - No account required
  - Uses Web Crypto API for cryptographically secure random generation
  - All data stored locally in your browser

🎯 PERFECT FOR

- Creating strong passwords for new accounts
- Generating secure passphrases that are easy to remember
- Quick PIN code generation
- Developers who need test passwords
- Anyone who values privacy and security

🔒 PRIVACY COMMITMENT

Unlike other password generators, Pswdgen:
- Never sends data to external servers
- Doesn't require account registration
- Doesn't track your usage
- Stores history only locally (you can clear it anytime)
- Open source logic based on pswdgen.com

💡 HOW TO USE

1. Click the extension icon or use keyboard shortcut
2. Choose your generation type (Password/Passphrase/PIN)
3. Customize settings to your needs
4. Click "Generate"
5. Click "Insert" to auto-fill or "Copy" to clipboard

All your settings are automatically saved for next time!

🌐 BASED ON PSWDGEN.COM

This extension brings the power of pswdgen.com directly to your browser with added convenience features like auto-insert and context menu integration.
