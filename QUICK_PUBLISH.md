# 🚀 Quick Publish Guide

Быстрая инструкция для публикации на GitHub

## Шаг 1: Создай репозиторий (2 минуты)

1. Открой https://github.com/new
2. Заполни:
   - Name: `pswdgen-chrome-extension`
   - Description: `🔐 Secure password generator Chrome extension`
   - Public ✓
3. Нажми "Create repository"

## Шаг 2: Запусти скрипт (1 минута)

```bash
cd chrome-extension
bash init-git.sh
```

Введи свой GitHub username когда попросит.

## Шаг 3: Push на GitHub (1 минута)

```bash
git branch -M main
git push -u origin main
```

## Шаг 4: Создай Release (2 минуты)

2. Заполни:
   - Tag: `v1.0.0`
   - Title: `🎉 v1.0.0 - Initial Release`
   - Description: (скопируй из CHANGELOG.md)
3. Нажми "Publish release"

## Шаг 5: Настрой репозиторий (2 минуты)

1. Settings → About:
   - Website: `https://pswdgen.com`
   - Topics: `chrome-extension`, `password-generator`, `security`, `privacy`

Теперь:
- ✅ Репозиторий опубликован
- ✅ Release создан
- ✅ Готово к использованию
